# Haetae (해태) - Contract-Driven Silent Assistant

Silent, contract-driven on-device coding assistant with in-memory verification.

## Features
- **Inline Synthesis (Ctrl+I)**: Silent code generation at cursor with zero conversational noise.
- **Comment Refactor Card (Alt+C)**: Native comments review and inline diff replacement.
- **In-Memory Verification (Alt+V)**: libtcc compilation + 10,000 micro-fuzzing runs with hardware trap diagnostics.
- **Hardware Boost (/boost)**: 12-stage live hardware and engine pipeline benchmark.
